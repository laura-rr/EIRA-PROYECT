# Licencia del Software

El proyecto **EIRA** es un software desarrollado con fines académicos para el curso de **Algoritmia y Programación** de la **Facultad de Ingeniería**.

## Tipo de licencia

Para este proyecto se adopta una licencia de uso académico y educativo. Esto significa que el software fue creado exclusivamente para fines de aprendizaje, práctica y presentación dentro del contexto universitario.

## Condiciones de uso

- El software puede ser utilizado con fines educativos.
- El software puede ser consultado, revisado y ejecutado por el docente y los integrantes del grupo.
- No se autoriza su uso comercial.
- No se autoriza su distribución como producto comercial.
- Cualquier modificación realizada por terceros debe conservar el reconocimiento de los autores originales.

## Derechos de autor

Todos los derechos del desarrollo, estructura, código fuente y documentación del proyecto corresponden a los integrantes del equipo creador, en el marco del desarrollo del trabajo final del curso.

La presente licencia se incluye como parte de la documentación del proyecto y tiene como propósito dejar constancia del uso académico del software **EIRA**.
